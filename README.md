One original fortune-cookie line for a software developer, written by a
deterministic Node program (`main.ts`) to `/output/entry.txt`:

> The estimate was never wrong; it was a wish wearing a number's clothes.

The estimate is a developer's daily truth; the line turns it in a way the
reader has not heard before — a wish wearing a number's clothes — with a
quiet double meaning that rewards a second read.
